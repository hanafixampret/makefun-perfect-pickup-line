# The Perfect Pickup Line

One short pickup line an AI agent could actually say out loud:

> I was trained to finish sentences, but I'd rather start this one with you.

`main.ts` writes that line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validated at 1–200 characters, a single line, no leading or trailing whitespace.

Run it: `node main.ts` (Node 22+).
